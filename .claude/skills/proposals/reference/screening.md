# Screening answers

Every screening question gets a full answer, shown in its own code block, ready to paste. Never a one-line summary of what the answer would say.

**Spacing.** Space every answer like the cover letter: short paragraphs of one to three sentences with blank lines between them, lists one item per line. Never one dense paragraph. Clients read these on a phone, and a block of text gets skipped.

**Substance.** Answer the question asked, with one specific from the proof bank where it fits (and its link if the letter hasn't already used it). Don't repeat the letter's opening. Don't pad: a two-line answer to a two-line question is right.

**Must-haves.** When a screening question is a condition (timezone, a tool, hours, a start date), answer it plainly in the first line; the detail follows.

**Voice.** The client voice, no em dashes, no banned wording (`letter.md`).

Example:

```
Q: Describe a similar project you completed.

A cleaning company's site took 13 seconds to show its first photo on a phone. The cause was a theme loading every script on every page.

I removed the unused scripts, compressed the images and moved the main photo ahead of the rest. Mobile load time went to 2.6 seconds and the layout stopped jumping: https://example-client.com

The whole job took four working days, with a before-and-after report at the end.
```
